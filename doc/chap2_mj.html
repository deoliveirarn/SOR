2 How the groups are built

2.1 Free products with embeddings

Every group of this package is a quotient \(Q = (G_1 * \cdots * G_n)/N\) of a free product of copies of the input group \(G\), where \(N\) is the normal closure of the defining relations. The construction starts from FreeProduct of GAP, which accepts groups in any representation, and keeps the embeddings \(G \to G_i\) given by Embedding. The images of the generators of \(G\) are carried through the quotient and through the conversion of \(Q\) into a pc group, and the embeddings \(G \to Q\) are stored with the result.

This is what makes the subgroups of \(Q\) cheap to compute. For instance, in \(\chi(G)\) the subgroups \(L(G)\), \(D(G)\), \(W(G)\) and \(R(G)\) are defined in terms of the two copies \(G\) and \(G^\psi\) and of the isomorphism \(\psi\) between them; with the embeddings at hand they are direct computations inside a pc group. Without them, one has to locate the copies of \(G\) inside the computed group, which is a search, or to carry every element of \(G\) through a presentation by hand.

For example, the pc group \(\chi(Q_8)\) below has \(7\) generators in its pcgs, with no visible relation to the generators of \(Q_8\); the embeddings give the two copies of \(Q_8\) inside it at once, and \(D = [G, G^\psi]\) and \(L\) are then single commands:

gap> G := SmallGroup( 8, 4 );;   # the quaternion group
gap> C := SidkiChiGroup( G );;
gap> Length( Pcgs( C ) );
7
gap> H := Image( Embedding( C, 1 ) );;  Hpsi := Image( Embedding( C, 2 ) );;
gap> Size( CommutatorSubgroup( H, Hpsi ) );   # D(G)
2
gap> Size( Subgroup( C, List( G, g ->
>      Image( Embedding( C, 1 ), g )^-1 * Image( Embedding( C, 2 ), g ) ) ) );   # L(G)
16

In our tests, for the group of order \(32\) SmallGroup(32,49), whose \(\chi(G)\) has order \(2^{21}\), \(\chi(G)\) is computed in about \(0.1\) seconds and \(L(G)\) and \(D(G)\) in a few milliseconds; computing \(L(G)\) by carrying the elements of \(G\) through a presentation, as in the author's earlier code, did not finish in ten minutes.

2.2 Strategy by class of groups

The finitely presented group \(Q\) is not a good group to compute in. The package replaces it by a group in which one can compute (a pc group, a pcp group or a subgroup of a direct product), choosing the construction from the class of \(G\). In every case the embeddings of the copies of \(G\) are kept.

For \(\chi(G)\) (SidkiChiGroup (3.1-1)) the methods are tried in this order:

  • \(G\) finite or polycyclic, generated by two elements, with trivial Schur multiplier: then \(R(G) = 1\) [KM21, Lemma 9.3] and \(W(G)/R(G) \cong M(G) = 1\) [Roc82], so \(\chi(G)\) is the subgroup \(T(G)\) of \(G \times G \times G\) of Sidki [Sid80]. This includes non-solvable groups, such as \(PSL(2,8)\).

  • \(G\) finite and perfect: \(\chi(G) = T(\tilde G)\), where \(\tilde G\) is the universal covering group of \(G\) [Sid80, Theorem 4.4.1].

  • \(G\) an infinite polycyclic group generated by two elements: \(\chi(G)\) is the group \(\tau(G) = \tau^0(G)\) of Dias and Rocco [DR20], which is \(\chi(G)/R(G)\), and \(R(G) = 1\). For other polycyclic groups, SidkiChiModRGroup (3.2-1) gives \(\chi(G)/R(G)\).

  • \(G\) a finite \(p\)-group: \(\chi(G)\) is a finite \(p\)-group (Sidki), so it is the largest \(p\)-quotient of \(Q\), computed by EpimorphismPGroup without a bound on the class.

  • \(G\) finite and solvable: \(\chi(G)\) is a finite solvable group whose order involves only the primes dividing \(|G|\) (Sidki), so it is the largest such solvable quotient of \(Q\), computed by EpimorphismSolvableQuotient.

For other groups, SidkiChiModWGroup (3.3-1) gives \(\chi(G)/W(G)\) as a subgroup of \(G \times G \times G\).

The user may also choose the method, with a second argument: SidkiChiGroup (3.1-3) and RoccoNuGroup (5.1-3). The method "fp" returns the finitely presented group itself, for any finite \(G\), leaving to the user what to compute in it.

For \(\nu(G)\) (RoccoNuGroup (5.1-1)): if \(G\) is a finite \(p\)-group, Rocco's presentation [Roc94], with \(x\), \(y\) in a pc generating sequence, and the largest \(p\)-quotient; if \(G\) is finite solvable or polycyclic, the nonabelian tensor square of the package Polycyclic [EN08]. For \(\tau^q(G)\) (RoccoTauGroup (6.1-1)): a polycyclic presentation following Dias and Rocco [DR20], for \(G\) finite solvable or polycyclic. For \(\chi(n,H)\) (SidkiChiNGroup (4.1-1)): \(T_n(\tilde H)\) if \(H\) is finite and perfect, and the largest \(p\)-quotient if \(H\) is a finite \(p\)-group.

One example of each case:

gap> SetInfoLevel( InfoSOR, 0 );
gap> Size( SidkiChiGroup( SymmetricGroup( 3 ) ) );    # T(G) in G x G x G
108
gap> Size( SidkiChiGroup( AlternatingGroup( 5 ) ) );  # perfect: T(H~)
432000
gap> C := SidkiChiGroup( DihedralPcpGroup( 0 ) );;    # infinite: tau(G)
gap> IsFinite( C );  HirschLength( C );
false
3
gap> Size( SidkiChiGroup( DihedralGroup( 8 ) ) );     # p-group
256
gap> Size( SidkiChiGroup( AlternatingGroup( 4 ) ) );  # finite solvable
1152
gap> Size( RoccoNuGroup( DihedralGroup( 8 ) ) );      # Rocco 1994
2048
gap> Size( RoccoNuGroup( SymmetricGroup( 3 ) ) );     # Polycyclic
216

2.3 Time limits

GAP has no time limit for a computation inside the running session. The function IO_CallWithTimeout of the IO package (a separate package, not needed by SOR, distributed with GAP and loaded with LoadPackage( "io" )) runs a function in a copy of the session (a forked process) and stops it after the given time, returning [ true, result ], or [ false ] if the time ran out. The result is sent back from the copy, which works for numbers, lists and strings but not for groups: ask the copy for the invariants you need, and compute the group itself in the session (or take SidkiChiGroup( G, "fp" )) when it is worth it.

gap> LoadPackage( "io" );;
gap> IO_CallWithTimeout( rec( seconds := 60 ),
>        G -> Size( SidkiChiGroup( G ) ), SmallGroup( 8, 4 ) );
[ true, 128 ]
gap> IO_CallWithTimeout( rec( seconds := 1 ),
>        function() while true do od; end );   # never finishes
[ false ]
