7 Weak commutativity by bijections

7.1 Construction

Let \(H\) be a finite group, \(\dot H\) an isomorphic copy of \(H\), and \(\sigma : H^\# \to \dot H^\#\) a bijection, where \(H^\# = H \setminus \{1\}\). The weak commutativity group defined by \(\sigma\) is

\[\chi(H,\sigma) = \langle H, \dot H \mid [h, h^\sigma] = 1 \ \forall h \in H^\# \rangle\]

[OS09]. When \(\sigma\) is the isomorphism \(\psi\), it is Sidki's group \(\chi(H)\). The group \(\chi(H,\sigma)\) is the group \(S(H, \dot H; \sigma, \sigma, 1)\) of Sidki [Sid80, Theorem 3.5 and Remark 3.3 (iii)], hence it is finite for every finite \(H\). The package computes it exactly, by coset enumeration in the finitely presented group, and returns a pc group when it is solvable and a permutation group otherwise.

Oliveira and Sidki [OS09] conjecture that \(\chi(H,\sigma)\) is a finite \(p\)-group whenever \(H\) is a finite \(p\)-group. This is open, so the package does not take the largest \(p\)-quotient for the group: IsPGroup of the result tests the conjecture for the given \(\sigma\).

A bijection \(\sigma\) is given by a permutation \(s\) of \([1 .. |H| - 1]\): if \(H^\# = [ h_1, \ldots, h_{|H|-1} ]\) is the list SidkiNonIdentityElements (7.1-1), then \(\sigma(h_i)\) is the copy of \(h_{i^s}\). The identity permutation gives \(\chi(H)\).

7.1-2 SidkiBijectionAsPermutation
‣ SidkiBijectionAsPermutation( H, f )( function )

Returns: a permutation

The permutation of \([1 .. |H|-1]\) that encodes the bijection given by f, a function from \(H^\#\) to \(H^\#\) or the list of the images of SidkiNonIdentityElements (7.1-1).

gap> H := CyclicGroup( 4 );;
gap> Length( SidkiNonIdentityElements( H ) );
3
gap> SidkiBijectionAsPermutation( H, x -> x^-1 );   # inversion on H#
(1,3)

7.1-3 SidkiChiGroupByBijection
‣ SidkiChiGroupByBijection( H, s )( operation )

Returns: a pc group or a permutation group

Returns \(\chi(H,\sigma)\) for a finite group H and the permutation s encoding \(\sigma\), computed exactly. Embedding(C , 1) and Embedding(C, 2) are the embeddings of \(H\) and \(\dot H\), and SidkiD (3.5-1) is \([H, \dot H]\). Coset enumeration limits this to groups of moderate order.

gap> H := ElementaryAbelianGroup( 8 );;
gap> Size( SidkiChiGroupByBijection( H, () ) ) = Size( SidkiChiGroup( H ) );
true
gap> C := SidkiChiGroupByBijection( H, (1,2) );;
gap> Size( C );  IsPGroup( C );
1024
true
gap> Size( SidkiChiGroupByBijection( CyclicGroup( 8 ), (1,5,3) ) );   # cyclic: H x H
64

7.2 Reductions (Oliveira and Sidki, 2009)

For \(\alpha \in \mathrm{Aut}(H)\) and \(\beta \in \mathrm{Aut}(\dot H)\), \(\chi(H,\sigma) \cong \chi(H, \alpha\sigma\beta)\); so it suffices to let \(\sigma\) run over the double cosets \(\mathrm{Aut}(H) \backslash \mathrm{Sym}(H^\#) / \mathrm{Aut}(H)\). For an elementary abelian group \(H = C_p^n = \langle a_1, \ldots, a_n \rangle\), every class contains a \(\tilde\sigma\) with \(a_i^{\tilde\sigma} = \dot a_i\); and, for \(p\) odd, every \(\chi(H,\sigma)\) is a quotient of some \(\chi(H,\hat\sigma)\) with \(\hat\sigma\) permuting the cyclic subgroups of \(H\) (Sidki). For cyclic \(H\), \(\chi(H,\sigma) \cong H \times \dot H\) for every \(\sigma\) (Oliveira and Sidki 2009, Proposition 5).

7.2-1 SidkiBijectionClasses
‣ SidkiBijectionClasses( H )( function )

Returns: a list of pairs

Representatives of the double cosets \(\mathrm{Aut}(H) \backslash \mathrm{Sym}(H^\#) / \mathrm{Aut}(H)\), as pairs [ s, size ], with s a permutation encoding \(\sigma\) and size the number of bijections in the class.

7.2-2 SidkiBasisFixingBijection
‣ SidkiBasisFixingBijection( H, s )( function )

Returns: a permutation

For an elementary abelian group H, with basis \(a_1, \ldots, a_n\) the pc generators of H, a permutation encoding a bijection \(\tilde\sigma = \alpha\sigma\beta\) (\(\alpha, \beta\) automorphisms) with \(a_i^{\tilde\sigma} = \dot a_i\), so that \(\chi(H,\tilde\sigma) \cong \chi(H,\sigma)\).

7.2-3 SidkiCyclicSubgroupGenerators
‣ SidkiCyclicSubgroupGenerators( H )( function )

Returns: a list

For an elementary abelian \(p\)-group H, one generator of each subgroup of order \(p\), normalised so that its first nonzero coordinate (with respect to the pc generators) is \(1\).

7.2-4 SidkiSubgroupPermutingBijection
‣ SidkiSubgroupPermutingBijection( H, tau[, t] )( function )

Returns: a permutation

For an elementary abelian \(p\)-group H with cyclic subgroups \(\langle u_1 \rangle, \ldots, \langle u_k \rangle\) (SidkiCyclicSubgroupGenerators (7.2-3)), a permutation tau of \([1..k]\) and optionally a list t of nonzero residues mod \(p\) (the twists, default \(1\)), the permutation encoding the bijection \(u_i^j \mapsto \dot u_{\tau(i)}^{t_i j}\), which permutes the cyclic subgroups.

7.2-5 SidkiInducedPermutation
‣ SidkiInducedPermutation( H, s )( function )

Returns: a permutation or fail

If the bijection encoded by s maps each cyclic subgroup of the elementary abelian group H onto a cyclic subgroup, the induced permutation \(\tau\) of \([1..k]\); otherwise fail.

7.2-6 SidkiSubgroupPermutationClasses
‣ SidkiSubgroupPermutationClasses( H )( function )

Returns: a list of pairs

For an elementary abelian group H, representatives \(\tau\) of the double cosets of \(\mathrm{Aut}(H)\), acting on the \(k\) cyclic subgroups, in \(S_k\), as pairs [ tau, size ].

gap> Length( SidkiSubgroupPermutationClasses( ElementaryAbelianGroup( 25 ) ) );

gap> Length( SidkiCyclicSubgroupGenerators( H ) );

gap> SidkiInducedPermutation( H, s );
