3 The weak commutativity group

3.1 Construction

Let G be a group and G^\psi an isomorphic copy of G, with \psi : G \to G^\psi an isomorphism. Sidki's weak commutativity group is

\chi(G) = \langle G, G^\psi \mid [g, g^\psi] = 1 \ \forall g \in G \rangle.

Here it is computed as the quotient of the free product G * G by these relations, keeping the two embeddings of G.

3.1-1 SidkiChiGroup
‣ SidkiChiGroup( G )( attribute )

Returns: a group

Returns \chi(G) for a group G given in any representation (permutation, pc, pcp, matrix or finitely presented) that is finite solvable, finite perfect, finite or polycyclic generated by two elements with trivial Schur multiplier, or infinite polycyclic generated by two elements; the method for each case is in the section Strategy by class of groups. The result is a pc group, a pcp group or a subgroup of a direct product. Embedding(C, 1) and Embedding(C, 2) are the embeddings of G and of G^\psi into it, and SidkiPsi (3.1-2) is \psi. For any other finite group, the form with two arguments (SidkiChiGroup (3.1-3)) returns \chi(G) as a finitely presented group.

3.1-2 SidkiPsi
‣ SidkiPsi( C )( attribute )

Returns: an isomorphism of groups

For a group C returned by SidkiChiGroup (3.1-1), the isomorphism \psi from the first copy of G in C to the second.

gap> G := SmallGroup( 8, 4 );;  C := SidkiChiGroup( G );;  psi := SidkiPsi( C );;
gap> ForAll( GeneratorsOfGroup( G ), g ->
>      Image( psi, Image( Embedding( C, 1 ), g ) ) = Image( Embedding( C, 2 ), g ) );
true

gap> G := SmallGroup( 8, 4 );;   # the quaternion group
gap> C := SidkiChiGroup( G );;
gap> Size( C );
128
gap> H := Image( Embedding( C, 1 ) );;  Hpsi := Image( Embedding( C, 2 ) );;
gap> Size( H ) = 8 and Size( Hpsi ) = 8;
true
gap> ForAll( G, g -> IsOne( Comm( g^Embedding( C, 1 ), g^Embedding( C, 2 ) ) ) );
true
gap> P := Image( IsomorphismPermGroup( G ) );;   # same group, other representation
gap> Size( SidkiChiGroup( P ) );
128

3.1-3 SidkiChiGroup
‣ SidkiChiGroup( G, method )( operation )

Returns: a group

With a second argument method, a string, the user chooses how \chi(G) is computed; except for "auto", the result does not become the value of SidkiChiGroup(G):

"auto"

the choice of the form with one argument;

"fp"

the finitely presented group (G * G^\psi)/\langle\langle [g, g^\psi] : g \in G \rangle\rangle itself, for any finite G, also when no other method applies; what to compute in it is left to the user (for instance AbelianInvariants, EpimorphismPGroup with a bound on the class, or Size by coset enumeration);

"T"

T(G) \le G \times G \times G, for G finite or polycyclic, generated by two elements, with trivial Schur multiplier, not given as a finitely presented group;

"perfect"

T(\tilde G), for G finite and perfect, not given as a finitely presented group;

"tau"

\tau(G), for G polycyclic (finite solvable or a pcp group) generated by two elements;

"pquotient"

the largest p-quotient of the finitely presented group, for G a finite p-group;

"solvable"

its largest solvable quotient whose order involves only the primes dividing |G|, for G finite and solvable.

The section Strategy by class of groups gives the theorem behind each method. Each method checks the hypothesis of its theorem and stops with an error if it fails, so the result is always \chi(G), never a proper quotient. Embedding and SidkiPsi (3.1-2) work for every result.

gap> G := SymmetricGroup( 5 );;   # no method computes chi(G) yet
gap> Q := SidkiChiGroup( G, "fp" );;
gap> AbelianInvariants( Q );      # chi(G)^ab = G^ab x G^ab
[ 2, 2 ]
gap> Size( SidkiChiGroup( SymmetricGroup( 3 ), "fp" ) );   # coset enumeration
108
gap> Size( SidkiChiGroup( SmallGroup( 8, 3 ), "tau" ) );   # R(G) = 1 here
256
gap> SidkiChiGroup( AlternatingGroup( 4 ), "T" );   # M(A_4) = C_2: refused
Error, SidkiChiGroup: "T" needs trivial Schur multiplier M(G)

3.2 Polycyclic groups

For a polycyclic group G, the group \tau(G) = \nu(G)/\Delta(G) of Dias and Rocco [DR20] (see RoccoTauGroup (6.1-1) with q = 0) is isomorphic to \chi(G)/R(G), the copies G and G^\varphi going to G and G^\psi. If G is generated by two elements then R(G) = 1 [KM21, Lemma 9.3], so \tau(G) is a consistent polycyclic presentation of \chi(G) itself, also for infinite G.

Returns \chi(G)/R(G) for a polycyclic group G (finite solvable in any representation, or a pcp group), as the pcp group \tau(G), with Embedding and the subgroups of SidkiD (3.5-1) and the following ones available. For a pcp group with at most two generators, SidkiChiGroup (3.1-1) uses this.

gap> C := SidkiChiGroup( DihedralPcpGroup( 0 ) );;   # infinite dihedral group

false
gap> Size( SidkiD( C ) ) = infinity and IsTrivial( SidkiR( C ) );
true
gap> Size( SidkiChiModRGroup( SmallGroup( 32, 34 ) ) ) =
>    Size( SidkiChiGroup( SmallGroup( 32, 34 ) ) ) / 4;   # |R| = 4 here
true

3.3 The quotient chi(G)/W(G) inside G x G x G

Sidki [Sid80]: the homomorphism \rho : \chi(G) \to G \times G \times G, g \mapsto (g, g, 1), g^\psi \mapsto (1, g, g), has kernel W(G); its image is denoted T(G). Rocco [Roc82]: W(G)/R(G) \cong M(G), the Schur multiplier. Hence \chi(G) \cong T(G) when R(G) = 1 and M(G) = 1, in particular when G is generated by two elements and M(G) = 1; this holds for groups of any kind, solvable or not.

3.3-1 SidkiChiModWGroup
‣ SidkiChiModWGroup( G )( attribute )

Returns: a group

Returns T(G) \cong \chi(G)/W(G), the subgroup of G \times G \times G generated by (g, g, 1) and (1, g, g), g \in G, with the embeddings g \mapsto (g, g, 1) and g \mapsto (1, g, g). For any group G. SidkiChiGroup (3.1-1) uses it when G is generated by two elements and has trivial Schur multiplier.

gap> G := AlternatingGroup( 4 );;   # M(G) = C_2, so W(G) <> 1
gap> C := SidkiChiGroup( G );;
gap> Size( SidkiChiModWGroup( G ) ) = Size( C ) / Size( SidkiW( C ) );
true
gap> Size( SidkiW( C ) );
2

gap> G := PSL( 2, 8 );;   # not solvable; 2-generated, M(G) = 1
gap> C := SidkiChiGroup( G );;
gap> Size( C ) = Size( G )^3;
true
gap> ForAll( GeneratorsOfGroup( G ), g ->
>      IsOne( Comm( g^Embedding( C, 1 ), g^Embedding( C, 2 ) ) ) );
true

3.4 Reduced presentations: weak commutativity on products of generators

Let S be a generating set of G and m \geq 1. Oliveira and Sidki [OS09, Section 4] define

\chi(G, S; m) = \langle G, G^\psi \mid [a, a^\psi] = 1 \ \forall a \in S \cup S^2 \cup \cdots \cup S^m \rangle,

where S^i is the set of products of i elements of S. There are two copies of G, as in \chi(G), and m bounds the length of the products; this is not the group \chi_n(H) with n copies of SidkiChiMotherGroup (4.1-2). The group \chi(G) is a quotient of \chi(G, S; m), and equal to it when m is large.

The group \chi(G, S; m) may be infinite for finite G: for G = C_2 \times C_2 and S = \{a_1, a_2\}, \chi(G, S; 1) contains a free abelian group of rank 2; and for G = C_2^3 the kernel of \chi(G, S; 2) \to \chi(G) is free abelian (Theorem 8). On the other hand, \chi(G, S; 2) = \chi(G) when G is abelian and generated by two elements (Corollary 1), and when G is finite abelian of odd order (Corollary 2). So the package returns the finitely presented group, with the embeddings of the two copies and the projection onto \chi(G), also finitely presented; quotients can be computed from it, for instance by EpimorphismPGroup with a bound on the class.

3.4-1 SidkiChiHatGroup
‣ SidkiChiHatGroup( G, m[, S] )( function )

Returns: a finitely presented group

Returns the finitely presented group \chi(G, S; m), where S is a generating set of the finite group G (by default GeneratorsOfGroup(G)) and m a positive integer. Embedding(C, 1) and Embedding(C, 2) are the embeddings of G and G^\psi, and SidkiChiHatProjection (3.4-2) is the projection onto \chi(G).

3.4-2 SidkiChiHatProjection
‣ SidkiChiHatProjection( C )( attribute )

Returns: a homomorphism

For C = \chi(G, S; m) returned by SidkiChiHatGroup (3.4-1), the natural epimorphism onto \chi(G) as a finitely presented group (SidkiChiGroup (3.1-3) with "fp"), which maps each copy of G to the corresponding copy: \chi(G) has the same generators and more relations, so the projection exists for every finite G. Its kernel is trivial exactly when \chi(G, S; m) = \chi(G). Composed with Embedding(C, i) it gives the embedding of the i-th copy of G into \chi(G); since that one is injective, so are the embeddings of G into \chi(G, S; m), also when this group is infinite. In the finitely presented \chi(G), Kernel and Size go through coset enumeration; when G is in one of the classes of Strategy by class of groups, the projection with "auto" below is much faster.

3.4-3 SidkiChiHatProjection
‣ SidkiChiHatProjection( C, method )( operation )

The same projection, onto \chi(G) computed by SidkiChiGroup(G, method); for instance "auto" gives a group in which one can compute (a pc group, a pcp group or a subgroup of a direct product), when G is in one of the classes of Strategy by class of groups.

gap> SetInfoLevel( InfoSOR, 0 );

gap> A := ElementaryAbelianGroup( 27 );;   # odd order: Corollary 2
gap> P := Image( EpimorphismPGroup( SidkiChiHatGroup( A, 2 ), 3 ) );;

true

3.5 Subgroups of chi(G)

For C = \chi(G), with the copies G and G^\psi given by the embeddings:

  • L(G) = \langle g^{-1} g^\psi \mid g \in G \rangle, the kernel of \chi(G) \to G, g, g^\psi \mapsto g;

  • D(G) = [G, G^\psi], the kernel of \chi(G) \to G \times G;

  • W(G) = L(G) \cap D(G);

  • R(G) = [G, L(G), G^\psi].

3.6 Subgroups of nu(G)

For N = \nu(G), with the copies G and G^\varphi given by the embeddings [BdMR22]:

  • \Theta(G) = \langle g^{-1} g^\varphi \mid g \in G \rangle, the kernel of \nu(G) \to G, g, g^\varphi \mapsto g;

  • \Upsilon_1(G) = [G, G^\varphi] \cong G \otimes G, \Upsilon_2(G) = [\Theta(G), G], \Upsilon_3(G) = [\Theta(G), G^\varphi]; then \nu(G)' = \Upsilon_1 \Upsilon_2 \Upsilon_3;

  • \Delta(G) = \langle [g, g^\varphi] \mid g \in G \rangle, for finite G; then \nu(G)/\Delta(G) \cong \chi(G)/R(G).
