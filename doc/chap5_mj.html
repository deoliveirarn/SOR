5 Rocco's group nu(G)

5.1 Construction

Let \(G^\varphi\) be an isomorphic copy of \(G\). Rocco's group is

\[\nu(G) = \langle G, G^\varphi \mid [x, y^\varphi]^z = [x^z, (y^z)^\varphi] = [x, y^\varphi]^{z^\varphi} \ \forall x, y, z \in G \rangle,\]

and the subgroup \([G, G^\varphi]\) of \(\nu(G)\) is isomorphic to the non-abelian tensor square \(G \otimes G\) [Roc91].

Two methods are used, both keeping the embeddings of \(G\) and \(G^\varphi\):

  • finite \(p\)-groups: the quotient of the free product \(G * G\) by the relations of Rocco [Roc94] for an AG-system \(a_1, \ldots, a_n\) of \(G\), \([a_i, a_j^\varphi]^{a_k} = [a_i^{a_k}, (a_j^{a_k})^\varphi] = [a_i, a_j^\varphi]^{a_k^\varphi}\), followed by its largest \(p\)-quotient;

  • other finite solvable groups and polycyclic groups: the function NonAbelianTensorSquarePlus of the Polycyclic package [EN08], whose first \(2n\) generators are the images of the \(n\) generators of \(G\) and of \(G^\varphi\).

5.1-1 RoccoNuGroup
‣ RoccoNuGroup( G )( attribute )

Returns: a pc group (finite \(p\)-groups) or a pcp group

Returns \(\nu(G)\) for a finite solvable group or a polycyclic group G. A finite G may be given in any representation; an infinite polycyclic one must be a pcp group. Embedding(N , 1) and Embedding(N, 2) are the embeddings of \(G\) and of \(G^\varphi\) into the result, and RoccoPhi (5.1-2) is \(\varphi\). For any other finite group, the form with two arguments (RoccoNuGroup (5.1-3)) returns \(\nu(G)\) as a finitely presented group.

5.1-2 RoccoPhi
‣ RoccoPhi( N )( attribute )

Returns: an isomorphism of groups

For a group N returned by RoccoNuGroup (5.1-1), the isomorphism \(\varphi\) from the first copy of \(G\) in N to the second.

gap> D := DihedralGroup( 8 );;  N := RoccoNuGroup( D );;  phi := RoccoPhi( N );;
gap> ForAll( GeneratorsOfGroup( D ), g ->
>      Image( phi, Image( Embedding( N, 1 ), g ) ) = Image( Embedding( N, 2 ), g ) );
true

gap> G := SymmetricGroup( 3 );;
gap> N := RoccoNuGroup( G );;
gap> Size( N );
216
gap> T := CommutatorSubgroup( Image( Embedding( N, 1 ) ),
>                             Image( Embedding( N, 2 ) ) );;
gap> Size( T );   # the order of the tensor square of S_3
6
gap> Size( RoccoNuGroup( SmallGroup( 32, 49 ) ) ) = 2^26;
true

5.1-3 RoccoNuGroup
‣ RoccoNuGroup( G, method )( operation )

Returns: a group

With a second argument method, a string, the user chooses how \(\nu(G)\) is computed; except for "auto", the result does not become the value of RoccoNuGroup(G):

"auto"

the choice of the form with one argument;

"fp"

the finitely presented group of the definition, for any finite G, also when no other method applies, with \(x\), \(y\) running over all elements of \(G\) and \(z\) over a small generating set (SmallGeneratingSet; this is enough: the relations for \(z_1\) and \(z_2\) give those for \(z_1 z_2\)); what to compute in it is left to the user. With \(k\) generators there are \(2k(|G|-1)^2\) relations, so in practice this is for small groups (for \(|G| = 168\) and \(k = 2\), about \(111\,000\));

"pquotient"

the presentation of Rocco (1994) and its largest \(p\)-quotient, for G a finite \(p\)-group;

"polycyclic"

NonAbelianTensorSquarePlus of the Polycyclic package, for G finite solvable or a pcp group.

Each method checks its hypothesis and stops with an error if it fails. Embedding and RoccoPhi (5.1-2) work for every result.

gap> N := RoccoNuGroup( AlternatingGroup( 5 ), "fp" );;   # no other method yet
gap> AbelianInvariants( N );   # nu(G)^ab = G^ab x G^ab
[  ]
gap> Size( RoccoNuGroup( SymmetricGroup( 3 ), "fp" ) );   # coset enumeration
216
gap> Size( RoccoNuGroup( DihedralGroup( 8 ), "polycyclic" ) );
2048
